# Alterações

## 1.0.0 — 2026-10-13

- Identidade unificada como Radar PNCP; código de coleta e monitoramento com nomes descritivos.
- Renomeação de módulos, funções, constantes, tabelas técnicas, CSS, componentes HTML, tarefas e arquivos de controle.
- Exportações e modelo Word com a identidade atualizada.
- Distribuição de código para GitHub sem bancos, logs, versões anteriores, caches ou dependências empacotadas.
- Instalação com ambiente virtual padrão e dependências fixadas nas versões da distribuição de origem.
- Migração offline dos bancos por cópia, mantendo a origem e preservando contadores e relações entre acompanhamentos.
- Verificador offline, testes de regressão e fluxo de validação para Linux e Windows no GitHub Actions.

O núcleo funcional foi mantido a partir da versão 0.7.30. Esta entrega concentra-se na mudança de identidade e na preparação do repositório; melhorias funcionais pendentes não foram incorporadas sem validação específica.
